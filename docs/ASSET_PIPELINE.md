# Локальный конвейер текстур и геометрии

В 0.2 реализована безопасная инвентаризация и проверка DDS. Извлечение/импорт NFS
контейнеров делегируется внешним инструментам, чьи реальные возможности описаны в
[TOOLS.md](TOOLS.md). Изменение игровых архивов установщиком 0.2 не выполняется.
Файлы игры отсутствуют в облаке; дальнейшие проверки выполняются на вашей копии.

## Подготовка и измерение

1. Закрыть игру, получить диагностический отчёт и SHA256 exe/ASI/INI. Не менять
   FusionFix, разрешение, MSAA, настройки симуляции. Создать отдельную рабочую копию
   нужных BIN/BUN/LZC **вне каталога игры**; исходники сохранить только локально.
2. Выполнить `python tools/assets.py --help` и использовать `inventory` для локального
   списка файлов и `dds-info` для экспортированного DDS. Отчёт не заменяет декодер
   контейнера и не показывает неизвестные текстуры внутри BIN как подтверждённые.
3. Зафиксировать для каждого ресурса: container path+hash, имя/hash текстуры, platform,
   dimensions, format/FourCC, mip count, назначение alpha, color space, repeat/clamp,
   материал/место использования. Для normal map — порядок/кодирование каналов.
4. Официальные UCGT/Binercover/TexEd устанавливаются отдельно. Первое извлечение
   выполнить без изменения ресурса. Точные команды зависят от выбранного snapshot;
   сверить `help` внешнего инструмента, а не копировать команды другой игры.

## Gate A: roundtrip без художественных изменений

Экспортировать один ресурс, импортировать обратно в копию и снова экспортировать.
Сравнить метаданные, **декодированные пиксели всех mipmaps** и соседние коллекции.
Повторная компрессия может поменять байты без видимого изменения; одного hash
контейнера недостаточно. Если побочный diff затронул физику, collision, AI, economy,
progression или SimRate — остановить этот pipeline и восстановить исходную копию.

Игровую проверку выполнять отдельной сессией с заранее подготовленным возвратом
оригинального файла. Пока нет manifest-backed asset installer, нельзя называть
такую ручную установку автоматически обратимой частью 0.2.

## Gate B: одна исходная авторская текстура

Начать с одной дороги или бетонной поверхности с однозначным texture ID. Изменять
материал/детали с учётом масштаба в мире, освещения и скорости движения. Генерация
деталей и upscale — художественная реконструкция, не восстановленные данные игры.
Оценивать тайлинг, стыки, перспективное мерцание и читаемость разметки, а не только
красоту неподвижного увеличенного кадра.

* Сохранять DXT1/DXT3/DXT5 или исходный uncompressed legacy формат при подтверждённой
  поддержке. DXT1 имеет ограничения прозрачности; замена smooth alpha на 1-bit alpha
  повредит листья/дым/стекло. Не считать BC7, DX10 header и sRGB DDS метаданные
  автоматически пригодными для native DX9 контейнера UC.
* Для цвета фильтровать mipmaps в правильном цветовом пространстве, для normals —
  перенормировать векторы. Для alpha test проверить покрытие на дальних mipmaps.
  Alpha может хранить specular/mask вместо прозрачности; назначение не угадывать.
* [DirectXTex](https://github.com/microsoft/DirectXTex) обрабатывает DDS, но не
  внедряет их в NFS. `texdiag` полезен для независимой проверки, `texconv` — для
  формата и mipmaps. Не применять одинаковую команду ко всем классам текстур.
* Меньшее разрешение, корректные mipmaps и качественный исходник могут дать более
  стабильную картинку. Удвоение каждой стороны увеличивает память примерно в 4 раза;
  полный mip chain добавляет примерно треть к top mip для больших 2D-текстур.

Предпочтительный будущий путь поставки: отдельный пакет только с авторскими
ресурсами и manifest (author/license/source/hash/target ID). Texture Wizard
потенциально позволяет такую поставку без замены штатных архивов, но hook conflicts
с FusionFix и конкретная версия загрузчика сначала должны пройти локальную проверку.

## Геометрия: последовательность без изменения геймплея

1. UCGT `dump` на копии контейнера; для world использовать **glTF/GLB**, поскольку
   OBJ теряет несколько UV-каналов дорог/тоннелей. Сохранить конфиг, marker names,
   bounds, material IDs, tangent/normal/color, indices, UV sets и исходные LOD.
2. Выполнить неизменённый decompile/compile/replace roundtrip в копии. Не включать
   массовую оптимизацию, переименование или `AutoReplaceWorldLODs` без отдельной
   оценки; не копировать high-poly во все уровни детализации.
3. Добавлять детали в пределах существующего visual mesh. Не менять collision/Havok,
   wheel/chassis/physics markers, physical dimensions или игровые vehicle records.
   Структурная замена без diff связанных коллекций не считается безопасной.
4. Проверить все LOD, направление normals, texture seams, shadow casting, streaming
   offsets и переходы блоков. Bounding volume влияет на видимость: изменение bounds
   требует отдельного off-by-default эксперимента и проверки исчезающих объектов.
5. Не обещать добавление новых world objects: upstream `replace` ищет существующие
   имена; новые meshes могут не загрузиться. Дальность прорисовки и culling не
   исправляются автоматически повышением полигональности.

## Материалы, автомобили и частицы

Nikki подтверждает существование UC Material/TPK/SunInfo менеджеров; это не карта
семантики всех полей. Первый материал: измерить specular/reflection, стекло и alpha
на одном штатном автомобиле при одинаковом солнце, затем изменить только известное
визуальное поле. Не импортировать целый чужой автомобиль ради материала.

Для particles сначала найти emitter/texture связь через копии данных или DX9 trace.
Отдельно измерить lifetime/count/size/alpha и overdraw. Не менять gameplay-linked
nitro intensity, acceleration, traction или visibility AI. В 0.2 новых emitter
patches нет: дым и нитро нельзя достоверно улучшить полноэкранным фильтром.

## Данные, необходимые для следующей итерации

Поделиться можно текстовым диагностическим отчётом (предварительно проверить пути),
метаданными DDS без изображения, скриншотами и измерениями по LOCAL_TESTING.md.
Не загружать exe, архивы игры, исходные DDS/mesh и полные GPU captures в публичный
репозиторий. Для нового ресурса хранить лицензию и доказательство происхождения.
