# Локальная приёмка Visual Foundation 0.2

Статус: **требует запуска игры**. Этот документ — протокол испытаний, а не отчёт
об успешном запуске. Облако не содержит вашей игры, GPU и Windows DX9 runtime.

## 1. Зафиксировать исходное состояние

Закройте игру. Сохраните отдельную копию сохранения средствами Windows/Steam.
Запустите diagnose и backup по README. Не публикуйте отчёт без проверки личных
путей. Запишите GPU/VRAM, драйвер, Windows, CPU/RAM, SHA256 nfs.exe, номер версии
FusionFix, ReShade, все моды и настройки. Сохраните исходные INI/CFG/ReShade.log
отдельно от Git. Диагностический ZIP не содержит игровые архивы или сохранение.

3440×1440, один и тот же режим окна, FOV, камера, машина и сохранение. Все
настройки игры/FusionFix, cap/VSync/MSAA остаются одинаковыми. **Не менять FPSLimit
или SimRate**: FusionFix может связывать ограничитель с симуляцией. Выключите
автоматическую экспозицию/улучшения изображения монитора, зафиксируйте SDR режим.
Для этого профиля нет верифицированного HDR workflow.

## 2. Зарегистрировать сцены один раз

Не выдумываем координаты без установленной игры. Выберите доступные в вашем
сохранении места и создайте локальный `local/scenes/` с картой и кадрами:

| ID | Что зафиксировать | Для чего |
|---|---|---|
| S01 | Выезд из гаража, машина неподвижна; солнце, небо, белый кузов/фара | Экспозиция, клиппинг, glare |
| S02 | Улица с деревьями/забором и длинной тенью | Листва, альфа, каскады, мерцание |
| S03 | Шоссе, одинаковый 60-секундный маршрут на высокой скорости | Читаемость, LOD/pop-in, кадры |
| S04 | Плотная застройка, бетон/асфальт/витрины; тоннель или эстакада | Материалы, тёмные детали |
| S05 | Одинаковое место для заноса и нитро, 20 секунд | Дым, пыль, искры, bloom |
| S06 | Меню/карта/ролик/гараж | HUD и нежелательная постобработка |

Для каждого ID сохраните снимок карты с маркером и направление камеры, стартовый
кадр, название события или способ доехать, автомобиль, погоду/игровое состояние.
Для движения запишите видео-ориентир и секундные отметки поворотов. При смене
освещения перезагрузите то же событие/сохранение; обычного цикла дня/ночи здесь нет.
Если состояние не воспроизводится, отметьте пару как несопоставимую.

## 3. Сравнение A/B

1. A: FusionFix в текущем рабочем состоянии, эффекты ReShade выключены. Проверьте,
   что сам запуск с новым ReShade не сломал загрузчик. Если сломал — остановите тест,
   восстановите официальным установщиком ReShade исходное состояние DLL.
2. B: только Clean. В ReShade проверьте отсутствие compile errors; сохраните лог,
   видимые версии и список активных техник. Не считать lint компиляцией.
3. C: Hybrid, затем Cinematic. Один профиль за раз; исключить эффекты старых
   пресетов. Сделайте одинаковые PNG A/B, включая HUD. Эффекты действуют и на HUD.
4. D: отдельный opt-in тест теней из FUSIONFIX.md. Постобработку и настройки A/B
   оставьте одинаковыми. Не смешивайте тени, LOD и цвет в одном сравнении.

Проверяйте белые облака и блики, оттенки кожи/кузовов, детали в тени, толщину
тонких линий, контраст дорожных знаков. Ухудшение читаемости в движении — причина
снизить эффект. Bloom не должен размывать стоп-сигналы и дорожную разметку.
Профиль не добавляет текстуры, отражения, геометрию, объёмный свет или настоящую GI.

## 4. Производительность

Прогрейте S03 минимум два прохода. Выполните по три 60-секундных записи A/B на
одном маршруте. Исключите меню, загрузку и alt-tab; не исключайте реальные
подёргивания в движении. Используйте официальный PresentMon/CapFrameX отдельно,
запишите его версию; не добавляйте ещё один DX9 proxy. Выберите один процесс и
swapchain. Зафиксируйте точное определение столбца и единицы **миллисекунды**.

```powershell
py -3 tools/benchmark.py local/A.csv --column msBetweenPresents --compare local/B.csv
```

Имя столбца зависит от версии инструмента; укажите существующий столбец времени
кадра. CPU/GPU busy не равны полному времени кадра. Анализатор не угадывает единицы.
Отчёт включает средний FPS, p95/p99, 1% low и долю кадров свыше бюджета. Сравните
медиану трёх прогонов, отдельно сохраните VRAM и температуру GPU.

Начальный ориентир для принятия: отсутствие новых вылетов/артефактов, отсутствие
заметной потери читаемости, уменьшение среднего FPS не более 10% для Hybrid и
отсутствие заметного ухудшения p99/VRAM thrashing. Это **критерий**, не обещанная
производительность. Cap может скрывать стоимость эффектов; не снимайте его ценой
изменения симуляции, используйте GPU timing из ReShade как дополнительную метрику.

## 5. Отказ и восстановление

Сначала выключите техники/выберите старый пресет. Верните shadow-значения по
записанному diff. Выполните dry-run удаления, затем uninstall из README. Повторите
S01/S03. Сравните исходные SHA256 FusionFix, nfs.exe и загрузчиков: они должны
остаться теми же. `restore` отменяет последнюю транзакцию нашего установщика;
это **не** восстановление всей игры и не удаление вручную установленного ReShade.

Сохраните отчёт по форме TEST_REPORT.md. Ни один профиль не получает отметку
«проверено в игре» до заполненного отчёта со скриншотами и логом компиляции.
