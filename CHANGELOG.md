# Changes

## 0.3.0 — Native Foundation (2026-11-05)

* Preserve the 0.2 payload, presets, installer ownership and archived release.
* Add portable C++17 config/policy, render-graph validation/scheduling, CPU grade
  reference and device lifecycle model with 14,112 always-active checks.
* Add native D3D9 SDR shader/backend, explicit state/reset ownership and standalone
  host with CPU readback/state/Reset checks requiring a local DX9 GPU.
* Integrate unmodified licensed official ReShade SDK API 20 source; experimental
  Win32 bridge defaults disabled and applies no game-address/proxy/physics patches.
* Add bounded passive shader metadata observer and strict read-only PE/import probe.
* Pin and inspect nfsuc, ExOpts, Modern Fix, UCGT and current FusionFix; distinguish
  console scaffolding, retail-only addresses and actual Steam source evidence.
* Add Linux/Win32 native CMake/CTest jobs including real ps_3_0 compilation.

GPU execution, add-on load order and Steam/FusionFix runtime compatibility remain
local test gates, separate from native compilation and synthetic tests.

## 0.2.0 — Visual Foundation (2026-11-02)

* Establish visual-only project policy and nfsuc-visual-modding agent skill.
* Add original ReShadeFX SDR grade/highlight shoulder and optional separable bloom.
* Add Clean, Hybrid and Cinematic presets containing only supplied techniques.
* Add Python/PowerShell diagnostics, config backup, isolated install, uninstall,
  transactional restore and interrupted-operation recovery with conflict guards.
* Inspect current FusionFix graphics source; document manual, disabled shadow/LOD
  studies without writing gameplay, FPSLimit, SimRate or existing configurations.
* Add local read-only DDS/container inventory and texture preflight, CSV frametime
  statistics, automatic tests, Linux/Windows CI and deterministic release manifest.
* Document tool licenses, geometry/texture roundtrip gates and local A/B protocol.

Release status: local test candidate; no Windows DX9 GPU or in-game validation yet.
